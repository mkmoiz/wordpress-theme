Metaxchron Futurism — Complete Blog Theme
===========================================
Features
- TIME-style landing page (Template: "Metaxchron Blog Landing")
- Featured hero, category ribbon, responsive grid
- Single, archive, search, 404 templates
- Orbitron + Poppins fonts, neon cyan→purple glow
- Demo content (Tools → Import → WordPress → upload demo-content.xml)

Install
1) Upload the zip in WordPress: Appearance → Themes → Add New → Upload Theme.
2) Activate the theme.
3) Create a page, choose Template "Metaxchron Blog Landing". Publish.
4) (Optional) Settings → Reading → Set that page as your homepage.

Demo Content
- Tools → Import → "WordPress" → install importer → upload demo-content.xml → Import.
