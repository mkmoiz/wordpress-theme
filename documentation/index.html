MetaXChron Theme Documentation

Welcome to the official documentation for the MetaXChron premium WordPress theme. This guide will help you install, configure, and customize your site to achieve the perfect futurism aesthetic.

1. Installation

  1. Download the theme zip file from your purchase dashboard.
  2. Log in to your WordPress Dashboard.
  3. Go to Appearance > Themes > Add New.
  4. Click Upload Theme and select the metaxchron.zip file.
  5. Click Install Now and then Activate.

2. Demo Import

Tip: Ensure you have the "One Click Demo Import" plugin installed if you wish to import sample content easily.
  1. Navigate to Appearance > Import Demo Data.
  2. Select the "Default Futurism" demo.
  3. Click Import. This may take a few minutes.

3. Customization

All theme settings are located in the native WordPress Customizer. Go to Appearance > Customize.

Header & Logo

  • Logo: Upload your main logo, retina logo (2x), and mobile logo.
  • Layouts: Choose between Default, Centered, or Minimal header styles.

Typography

  • Choose from a curated list of premium Google Fonts (Orbitron, Inter, etc.).
  • Adjust Line Height and Letter Spacing for headings.

Footer

  • Customize copyright text.
  • Enable/Disable social icons (LinkedIn, GitHub, etc.).
  • Toggle the "Scroll to Top" button.

4. Plugin Integrations

The theme automatically detects and styles the following plugins:

  • WooCommerce: Full shop support with dark mode compatibility.
  • Contact Form 7: Custom input styling to match the theme.
  • Elementor: Global color/font mapping.
